# Montagem do deck externo (13 × 10 m)

Animação 3D interativa da montagem do deck, passo a passo, com linha do tempo, câmeras e vista explodida.

- **Abrir a simulação:** https://renagod.github.io/deck/
- **Vídeo da montagem:** [montagem-deck.mp4](montagem-deck.mp4)
- **Vídeo de apresentação no local:** [apresentacao-deck-cenario.mp4](apresentacao-deck-cenario.mp4)

Use o botão **Ver no local** para ver o deck, a rampa de acesso e o píer no cenário do lago.

A página é um arquivo único (`index.html`) e funciona também sem internet.
